# Milliサポート

**最終更新日：** 2026年9月16日

Milliは、iPhoneとApple Watch向けの、プライバシーを重視したオフラインファーストの家計簿・個人資産管理アプリです。

## よくある質問

### Premiumを購入したのに機能がロックされている

Milli Premiumの画面を開き、**Restore Purchases**をタップしてください。Milli PremiumはあなたのApple Accountに紐づく1回限りの購入であるため、同じアカウントでサインインしているどのデバイスでも、追加費用なしで復元できます。

復元がうまくいかない場合は、購入時に使用したApple AccountでApp Storeにサインインしていることを確認したうえで、私たちまでメールでご連絡ください。

### Milli Premiumには何が含まれますか？

サブスクリプションではなく、1回限りのお支払いで以下が解除されます。

- **Unlimited accounts** — 必要な数だけアカウントと帳簿を管理できます
- **Unlimited categories** — あなたの考え方に合わせて支出を自由に整理できます
- **Smart tags** — カテゴリを超えて取引を絞り込み、グループ化できます
- **Backup & iCloud sync** — データを安全に保ち、すべてのデバイスで利用できます
- **Home screen widgets** — アプリを開かずに残高を確認できます
- **Apple Watch app** — 手首から直接支出を追加・確認できます

### 返金はどのように申請すればよいですか？

購入手続きはすべてAppleが取り扱っているため、私たちが直接返金を行うことはできません。[reportaproblem.apple.com](https://reportaproblem.apple.com)から返金をリクエストしてください。

### 財務データは非公開ですか？

はい。Milliにはサーバー、解析（アナリティクス）、広告、サードパーティ製SDKは一切ありません。あなたのデータはデバイス上にとどまり、iCloud同期をオンにした場合に限り、私たちがアクセスできないあなた自身の非公開のiCloudアカウントに保存されます。詳細は[プライバシーポリシー](../../privacy/ja/)をご覧ください。

### デバイス間でデータが同期されない

以下をご確認ください。

1. 両方のデバイスが**同じApple Account**でサインインしていること
2. **設定 → 自分の名前 → iCloud → iCloud Drive**がオンになっていること
3. Milliの設定内でiCloud同期が有効になっていること
4. 両方のデバイスが正常にインターネットに接続されていること

同期はバックグラウンドで行われ、数分かかることがあります。2台目のデバイスでアプリを開くと、通常すぐに確認が行われます。

### データをバックアップしたり、移行したりするにはどうすればよいですか？

Milliでは設定からバックアップファイルをエクスポートできます。安全な場所に保管してください。エクスポートされたファイルはあなたの管理下に置かれるため、銀行の明細書と同じように慎重に取り扱ってください。

### MilliはiPadで使用できますか？

Milliは現在iPhone専用に設計されています。iPadでは互換モードで動作しますが、レイアウトは大きな画面に最適化されていません。

### Face ID／パスコードロックをオフにするにはどうすればよいですか？

アプリの設定を開き、セキュリティのセクションでアプリロックを無効にしてください。変更を反映する前に一度認証を求められます。

### 為替レートが間違っているように見える

Milliはリアルタイムの為替レートを取得しません。設計上、ネットワーク通信を一切行わないためです。為替レートはあなた自身が入力する値であり、設定からいつでも更新できます。

### 不具合を見つけた／機能のリクエストがある

**ivnsjdev@gmail.com**までメールでお知らせください。上記の[お問い合わせ](#contact)に記載されている詳細情報を含む不具合報告は特に役立ちます。また、機能のリクエストも必ず目を通しています。

## Apple Watch

### Apple WatchにMilliをインストールするにはどうすればよいですか？

ウォッチアプリはiPhoneアプリのコンパニオンアプリであり、iPhoneアプリと一緒にインストールされます。iPhoneで**Watch**アプリを開き、**Available Apps**までスクロールして、Milliの横にある**Install**をタップしてください。自動アプリインストールがオンになっている場合は、すでにインストールされています。

Apple WatchアプリはMilli Premiumの一部です。Premiumが解除されるまで、ウォッチアプリには購入ボタンのないロック画面が表示されます。購入はiPhone側で行われ、その後自動的にウォッチに反映されます。

### ウォッチでは何ができますか？

- 表示中のアカウントの**その日の純額**を確認できます。これはその日の取引の合計であり、意図的にアカウントの全期間の残高とは異なります
- そのアカウントの**その日の取引**を確認できます
- **支出または収入を追加**：Digital Crownを回して金額を設定するか、金額部分をタップしてキーパッドで入力し、カテゴリを選択して**Save**をタップします
- **アカウントを切り替える**：画面上部のアカウントアイコンをタップします

ウォッチにはその日の情報のみが表示され、直近のごく一部の記録しか表示されません。ウォッチは全体の帳簿ではなく、一目で確認しすばやく入力するためのものです。

### iPhoneから離れた場所でもウォッチを使用できますか？

はい。ウォッチはiPhoneから最後に送られた数値を保持しているため、iPhoneが範囲外にあってもスピナーではなく実際の数値でアプリが開きます。入力した内容は、iPhoneと再び通信できるようになるまでキューに保存されます。

ただし、記録が帳簿に保存されるのはiPhone側であるため、両者が再び通信できるようになるまでは確定していません。待機中の内容を確定するには、iPhoneを範囲内に戻してMilliを開いてください。

### ウォッチで追加した記録がグレー表示になっている

グレー表示は、iPhoneがまだその記録を確認していないことを意味します。記録は失われたわけではなく、キューに入っている状態です。BluetoothまたはWi-FiをオンにしてiPhoneを範囲内に戻し、Milliを開いてください。記録が正式に登録されると表示が通常の色に変わります。

キューに入っている記録は、watchOSが送信のタイミングを決定するため、自動的に反映されるまでに数分かかることがあります。両方のデバイスで同時にMilliを開くのが、最も早く反映させる方法です。

### 記録が保存されずウォッチから消えてしまった

これは、記録の登録先だったアカウントまたはカテゴリがiPhone上に存在しなくなっている場合に起こります。多くの場合、ウォッチが範囲外にあり古い情報を保持している間に、iPhone側でそのアカウントまたはカテゴリが削除されたことが原因です。iPhone側に記録を登録できる先がないため、保存できないまま残るのではなく、ウォッチがその記録を削除します。まだ存在するカテゴリに対して記録を入力し直してください。

### 購入済みなのに「Apple Watch is Premium」と表示される

ウォッチは自分自身で購入状況を確認することができず、iPhoneから伝えられる情報に頼っています。ウォッチを近くに置いた状態でiPhoneのMilliを開くと、数秒以内にロックが解除されます。iPhoneから一度も情報を受け取っていないウォッチは常にロックされた状態で始まります。これは、購入状況が不明な場合は付与されたものとして扱わないためです。

それでもロックが解除されない場合は、まずiPhone側でPremiumが有効になっていることを確認し（有効でなければ**Restore Purchases**をタップしてください）、その後もう一度iPhoneでアプリを開いてください。

### ウォッチに金額の代わりにダッシュ（-）が表示される

ダッシュ表示は、ウォッチがiPhoneからまだ何も受信していないことを意味します。Milliは実際には0円ではないのに0円と表示することはありません。取引がない日と、同期されていないウォッチとは別のものだからです。ウォッチを近くに置いた状態でiPhoneのMilliを開き、最初の更新を送信してください。

### ウォッチとiPhoneで異なるアカウントが表示される

これは意図された動作です。ウォッチで選択するアカウントはウォッチ独自の選択であり、iPhoneで開いているアカウントを変更するものではありません。そのため、iPhone側の表示を変更することなく、手首から別の帳簿に記録することができます。変更するには、ウォッチ画面上部のアカウントアイコンをタップしてください。

ウォッチで選択したアカウントが後でiPhone側で削除された場合、ウォッチはiPhoneが現在開いているアカウントに自動的に切り替わります。

### ウォッチに古い数値が表示される

ウォッチを近くに置いた状態でiPhoneのアプリを開いてください。ウォッチはフォアグラウンドに表示されるたびに、またiPhoneが範囲内に戻るたびに最新情報を要求するため、通常は両者が近くにある状態になってから数秒以内に自動的に解消します。

解消しない場合は、Bluetoothがオンになっていること、**Watch**アプリで2台のデバイスのペアリングが維持されていること、両方のデバイスにMilliがインストールされていることを確認してください。

### ウォッチアプリの言語が正しくない

ウォッチはウォッチ自体のシステム言語ではなく、iPhone側のMilli内で設定された言語に従います。iPhoneのMilliの設定で言語を変更すると、次回の更新時にウォッチにも反映されます。
